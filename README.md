### \### 🌐 DocTranslate Pro

### 

### O \*\*DocTranslate Pro\*\* é uma aplicação web interativa desenvolvida em Python que permite a tradução de documentos de texto mantendo o design, o layout e as mídias originais (como logótipos, imagens, negritos e itálicos). O sistema processa o documento de forma inteligente e granular para evitar a mistura de idiomas e otimizar o uso de cotas das APIs. 

### 

### \### 🚀 Funcionalidades

### 

### \* \*\*Preservação de Mídias e Estilos:\*\* Algoritmo estrito de proteção XML que identifica e isola logótipos (blip/drawing) para que nunca sejam apagados ou desalinhados.

### \* \*\*Tradução Granular Inteligente:\*\* Processamento baseado em runs (estilos nativos do Word) em vez de parágrafos brutos, o que impede que documentos bilingues criem uma "salada de línguas".

### \* \*\*Deteção Automática de Redundância:\*\* Integração com Inteligência Artificial de IA linguística para pular trechos que já estejam no idioma de destino, poupando largura de banda e requisições.

### \* \*\*Fatiamento de Texto:\*\* Quebra automática de strings longas para respeitar os limites operacionais de caracteres da API.

### \* \*\*Controle de Cota Dinâmico (Privacy by Design):\*\* Campo seguro na barra lateral para o utilizador inserir o seu próprio e-mail, expandindo a cota diária sem expor os dados do desenvolvedor.

### \* \*\*UX Avançada:\*\* Barra de progresso em tempo real e exibição analítica de métricas (blocos e palavras verificadas).
